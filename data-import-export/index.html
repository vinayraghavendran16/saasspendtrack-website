How do I import a SaaS vendor spreadsheet?

Export your inventory as CSV and include vendor names, owners, costs, renewal dates, and notice periods when available. Check the mapped columns and resolve duplicate vendors before using the reports.

Start with a small batch

Import a handful of active contracts first. Check dates and source currencies, then add the rest or use sample data during your seven-day trial.

Export the view you need

Use CSV for renewal rosters and further analysis, PDF for shareable reports, and workspace JSON for backup where available.
